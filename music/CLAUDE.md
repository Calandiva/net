# music — 악기 교실

보컬 · 기타 · 베이스 · 건반 · 드럼 튜토리얼 + 코드 사전 + 튜너 + 메트로놈.
브라우저에서 돌고, 서버도 설치도 없다.

**지금 상태: 뼈대(와꾸)는 다 섰고 글은 짧다.** 기능(코드 사전 · 튜너 · 메트로놈 ·
악보 그리기)은 전부 실제로 동작한다. 파트별 튜토리얼 본문만 최소한으로 적어 두었다.

## 실행

```
python3 build.py     # src/*.js → index.html (의존성 없음, 1초)
open index.html      # 파일 더블클릭으로 실행. 서버 불필요
```

## 실행 환경 제약

- **서버 없음.** `index.html` 을 파일로 열거나 정적 호스팅만으로 완전히 동작한다.
- **빌드 단계가 하나 있다.** 브라우저는 `file://` 에서 ES 모듈을 CORS 로 막는다.
  소스는 진짜 모듈로 두고, `build.py` 가 IIFE 로 감싸 한 파일에 넣는다.
  번들러도 의존성도 없다(파이썬 표준 라이브러리만). `sy/build.py` 와 같은 물건이다.
- 마지막으로 본 탭만 `localStorage` 에 남는다. 막혀 있어도 그대로 돌아간다.
- **외부 이미지·폰트·라이브러리를 쓰지 않는다.** 악보 · 지판 · 건반은 전부 SVG 로
  코드가 그리고, 소리는 WebAudio 오실레이터로 만든다.

## 코딩 규약

유지보수 편의가 최우선이다.

- 매직 넘버 금지. 조정 가능한 값은 전부 `config.js` 로.
- **층을 섞지 않는다.** `theory/` 는 DOM 을 모르고, `render/` 는 화면 상태를 모르고,
  `lesson/` 은 자료일 뿐이다. 새 악기를 넣더라도 이 경계는 지킨다.
- 주석은 한국어로. "무엇을 하는지" 보다 **"왜 이렇게 했는지"** 를 적는다.
- **번들러가 단순하게 유지되도록 지키는 것들** (`build.py` 가 강제한다):
  - `import { a, b } from './x.js';` 형태만. default·별칭·네임스페이스 import 금지.
  - `export const/let/var/function/class 이름` 형태만. `export {}` 와 `export default` 금지.
  - 새 파일을 만들면 `build.py` 의 `MODULES` 에 의존성 순서로 추가한다.
  - 모듈 사이에 같은 이름을 export 하지 않는다(빌드가 이름 충돌을 잡아 준다).

## 음을 어떻게 담는가 — 여기가 제일 중요하다

음은 언제나 `{letter, alter, oct}` 다. 피치클래스(0~11) 하나로 들고 다니지 않는다.

```
letter : C=0 D=1 E=2 F=3 G=4 A=5 B=6   ← 오선 위 세로 자리를 정한다
alter  : -2 ~ +2                        ← ♭♭ ♭ ♮ ♯ ♯♯
oct    : 국제 표기 (가온다 = C4)
```

C♯ 과 D♭ 은 소리는 같아도 **악보에서 자리가 다르다.** 피치클래스만 들고 다니면
그 구별이 사라져서, C 의 ♭3 이 D♯ 으로 찍히는 사고가 난다. 도수에서 음을 만들 때는
반드시 `intervals.js` 의 `degToNote()` 를 쓴다 — 3도는 언제나 세 번째 글자가 된다.

그 대가로 `E7♯9` 의 ♯9 는 `F♯♯` 처럼 겹올림이 나온다. 이론상 맞는 철자이므로
그대로 두고, 화면에는 `voicing.js` 의 `alias` 가 `(= G)` 를 덧붙인다.

## 코드를 늘리려면

`theory/chords.js` 의 `CHORD_TYPES` 에 한 줄 넣고, 부르는 이름들을 `ALIAS` 에 적는다.

```js
m7b5: { sym: 'm7♭5', name: '하프 디미니시',
        degs: [d(1), d(3, -1), d(5, -1), d(7, -1)],
        hint: '마이너 2-5-1 의 첫 코드.' },
```

지판 운지 · 건반 배치 · 악보는 전부 `degs` 에서 자동으로 나온다. 따로 손댈 것이 없다.

## 음 개수와 생략 규칙

`theory/voicing.js` 가 정한다. 남기는 순서는 `intervals.js` 의 `keepRank()`:

| 순위 | 도수 | 왜 |
|---|---|---|
| 0 | 루트 | 코드의 이름 |
| 1 | 3음 (또는 sus 의 4·2음) | 밝은가 어두운가를 혼자 정한다 |
| 2 | ♭5 · ♯5 | 변형된 5도는 코드의 성격 자체다 |
| 3 | 7음 · 6음 | 7 코드인지 아닌지 |
| 4~ | 텐션 | 이름에 적힌 것(가장 높은 것 · 변형된 것)부터 |
| 9 | 완전5도 | 소리에 거의 영향이 없다. 제일 먼저 뺀다 |

13 코드에서 9 를 빼고 13 을 남기는 것이 이 규칙에서 나온다.
`bandOmit`(루트 · 완전5도)은 "밴드에서는 빼도 된다" 는 별개의 표시다.

## 지판 운지를 어떻게 찾는가

`theory/fretboard.js` 의 `findShapes()`. 4프렛 창을 0~14프렛까지 밀면서
줄마다 (뮤트 · 개방현 · 창 안의 해당 음) 후보를 만들고 전수로 조합한다.

거르는 조건: 필요한 음이 하나도 빠지지 않을 것 · 제일 낮게 울리는 음이 루트(분수코드면
지정된 베이스)일 것 · 손가락 네 개 안에 들어올 것.

**바레 판정이 손가락 수를 좌우한다.** 한 프렛에 연달아 붙은 줄들을 한 손가락으로
누르는 것인데, 그 구간에 개방현이나 뮤트가 끼어 있으면 바레가 그 줄까지 눌러 버리므로
바레가 아니다. `fingering()` 이 가능한 (프렛, 구간) 조합을 다 따져 손가락이 제일 적게
드는 것을 고른다. 이것 덕분에 `Dm9 = x53555`, `Cm11 = 8 8 8 8 8 10` 같은 진짜
운지가 나온다.

점수는 낮은 자리 · 적은 손가락 · 줄을 안 건너뛰는 것을 좋아한다. 개방현 덤은 낮은
자리에서만 준다 — 12프렛에서 개방현을 섞는 건 초보가 쓸 운지가 아니다.

## 악보를 어떻게 그리는가

`render/staff.js`. 자료 꼴은 이렇다.

```js
{ clef: 'treble' | 'bass' | 'perc',
  time: [4, 4],
  percMap: DRUM_MAP,                 // clef 가 'perc' 일 때만
  measures: [ [ev, ev, ...], ... ] }

ev = { p: 'C4' | ['E4','G4'] | null(쉼표),
       d: 1|2|4|8|16, dot: true,
       text: '아',                   // 오선 아래 (가사 · 손가락 번호 · 박 세기)
       label: 'Em' }                 // 오선 위 (코드 이름 · 도수)
```

- 세로 자리는 `letter`·`oct` 로 정한다(`stepToY`). 그래서 E♭ 과 D♯ 이 다른 줄에 앉는다.
- **화음은 기둥이 하나다.** 가운데 줄에서 가장 먼 음이 아래면 기둥은 위로, 위면 아래로.
  단 타악보는 예외다 — 손은 위, 발은 아래로 따로 간다(`DRUM_MAP` 의 `up`).
- 이어진 8·16분음표는 박 단위로 묶어 빔을 그린다. 방향마다 따로 묶는다.
- **기타 악보는 실제 소리보다 한 옥타브 높게 적는 것이 관례다.** `lesson/guitar.js` 와
  코드 사전의 기타 칸은 그렇게 적혀 있다. 새로 적을 때도 그 관례를 따르고 화면에 밝힌다.

## 파트 내용을 늘리려면

`lesson/*.js` 만 건드리면 된다. 화면(`ui/lesson.js`)은 자료 길이에 맞춰 늘어난다.

```js
steps:    [{ n, title, body: [줄, 줄], tip }]   // 단계
scores:   [{ title, spec, note }]               // 예시 악보 (spec 은 위 참고)
practice: [줄, 줄]                              // "오늘 할 것"
gear:     [줄]                                  // 준비물 칩
```

## 튜너가 옥타브를 틀리지 않는 이유

`audio/tuner.js`. 자기상관의 최댓값을 그냥 고르면 주기 T 의 배수에도 봉우리가 서서
한 옥타브 아래를 집는 일이 잦다. 그래서 McLeod 방식을 쓴다 — NSDF 로 정규화한 뒤
가장 높은 봉우리를 찾고, **그 높이의 88% 를 넘는 "첫" 봉우리**를 고른다.

- 계산량을 줄이려고 절반으로 솎아 낸 뒤(≈24kHz) 잰다. 매 프레임이 아니라
  `TUNER.periodMs`(45ms) 마다만 잰다. 한 번에 4ms 남짓 든다.
- `fftSize` 는 8192 다. 5현 베이스 B0(30.9Hz)의 주기를 담으려면 이만큼 필요하다.
- `clarityMin` 은 0.72. 배음이 기음보다 센 악기는 또렷함이 1.0 까지 안 올라간다.
- 검증: 배음이 기음보다 센 E1(41.2Hz)·E2(82.4Hz)에서 오차 0.0센트로 잡힌다.

## 메트로놈이 흔들리지 않는 이유

`audio/metronome.js`. `setInterval` 로 소리를 내면 타이머 지터가 그대로 들린다.
25ms 마다 깨어나 100ms 앞까지의 클릭을 **오디오 시계에 미리 예약**해 둔다.
화면 램프만 `setTimeout` 으로 따라 붙는다(눈은 조금 늦어도 된다).
