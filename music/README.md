# 악기 교실

보컬 · 기타 · 베이스 · 건반 · 드럼 다섯 파트의 튜토리얼과 예시 악보, 그리고
코드 사전 · 튜너 · 메트로놈이 들어 있는 웹 페이지. **학원에 가지 않고 이것만 보고
따라 할 수 있게** 만드는 것이 목표다.

서버도 설치도 필요 없다. `index.html` 을 열면 그만이다.

## 실행

- `index.html` 을 더블클릭하거나, 정적 호스팅에 올리면 된다.
- 소스를 고쳤다면 `python3 build.py` 로 `index.html` 을 다시 굽는다.

## 무엇이 들어 있나

### 파트별 튜토리얼 (보컬 · 기타 · 베이스 · 건반 · 드럼)

파트마다 다섯 단계로 나눠 적었고, 단계마다 요령이 한 줄씩 붙는다.
아래에는 **예시 악보**가 그려진다. 오선 · 음표 · 빔 · 쉼표 · 클레프까지
전부 코드가 SVG 로 그린 것이고, 이미지 파일은 한 장도 쓰지 않는다.
드럼은 타악보(하이햇 ✕, 스네어 ●, 킥은 기둥이 아래로)로 그린다.

> 지금 글은 **뼈대만** 채워 둔 상태다. 각 파트의 `steps` 에 항목을 더 넣으면
> 화면은 그대로 늘어난다. 늘리는 방법은 `CLAUDE.md` 에 적어 두었다.

### 코드 사전

코드 이름을 치면 — `Cmaj7`, `Am7`, `G7sus4`, `F♯m7♭5`, `B♭13`, `C/E` 처럼 —
**기타 · 베이스 · 건반** 세 악기에서 어떻게 잡는지 한 화면에 보여 준다.

- **잡을 음 개수를 1 개부터 고를 수 있다.** 개수를 줄이면 무엇이 남고 무엇이 빠지는지
  바로 바뀐다. 남기는 순서는 루트 → 3음 → 7음 → 텐션 → 완전5도.
- **생략할 수 있는 음을 왜 뺄 수 있는지까지 적는다.** 완전5도는 소리에 거의 영향이
  없어 제일 먼저 빠지고, 루트는 베이스가 치므로 밴드에서는 빼도 된다.
  반대로 ♭5·♯5 는 코드의 성격이라 뺄 수 없다.
- **1도 · 3도 · 5도 · 7도 · 9도 · 11도 · 13도가 색으로 구분된다.** 악보에서도,
  지판에서도, 건반에서도 같은 도수는 같은 색이다.
- **기타**: 실제로 잡을 수 있는 운지를 지판에서 찾아 코드 다이어그램 세 개를 그린다.
  바레와 손가락 개수까지 계산한다. 지판 전체 지도에는 생략한 음이 점선으로 남는다.
- **베이스**: 언제나 한 음이다. 낮은 음끼리 겹치면 뭉개지기 때문. 루트를 잡을 자리들을
  지판에 찍고, 워킹 베이스로 넓힐 때 쓰라고 코드톤 위치도 함께 보여 준다.
- **건반**: 왼손과 오른손을 나눠서 알려 준다. 건반 그림에 왼/오 표시가 붙고,
  큰보표(오른손 위 · 왼손 아래)에도 같은 색으로 그려진다.
- 각 악기마다 **소리 ▶** 버튼이 있다. 기타는 스트로크처럼 훑어서 난다.

### 튜너

마이크를 켜면 지금 내는 소리가 무슨 음이고 몇 센트 어긋났는지 바늘로 보여 준다.
FFT 가 아니라 **자기상관(NSDF, McLeod 방식)** 으로 기본 주파수를 찾는다 — 배음이
기음보다 센 악기(기타 저음현, 베이스)에서도 한 옥타브 아래로 잘못 읽지 않는다.
5현 베이스 B0(30.9Hz)부터 잡는다. 조율 프리셋(기타 표준/드롭D/반음 내림,
베이스 4·5현, 우쿨렐레)의 줄 이름을 누르면 기준음이 난다.

소리는 브라우저 밖으로 나가지 않는다. 서버가 없으니 나갈 곳도 없다.

### 메트로놈

`setInterval` 로 소리를 내면 흔들리므로, 오디오 시계에 미리 잡아 두는(lookahead)
방식을 쓴다. 한 마디 박(2~7), 쪼개기(4분·8분·셋잇단·16분), 첫 박 강조,
탭 템포를 고를 수 있고 박마다 램프가 켜진다.

## 만든 방식에 대해

- **그림은 전부 코드가 그린다.** 악보의 높은음자리표는 나선을 계산해서 그리고,
  낮은음자리표·타악기표·음표·빔·쉼표·지판·건반도 전부 SVG 로 만든다.
  웹폰트도 이미지도 외부 라이브러리도 쓰지 않는다.
- **소리도 코드가 만든다.** WebAudio 오실레이터에 배음 두 개를 얹은 것이 전부다.
- 구조와 규약은 `CLAUDE.md` 에 적어 두었다. 파트 내용을 늘리거나 코드를 추가하려면
  그쪽을 보면 된다.
