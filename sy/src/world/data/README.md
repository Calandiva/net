# world/data — 지역 데이터

이 폴더의 파일만 고치면 지도가 바뀐다. 렌더링 코드는 여기 값을 읽기만 한다.

- 좌표는 전부 **WGS84 [경도, 위도]** 쌍이다. 타일 변환은 `world/geo.js` 가 한다.
- 길이 단위는 **미터**. 타일 크기는 `config.js` 의 `GEO.metersPerTile` 로 정한다.
- `regions.js` 지면(시가지·논밭·산업단지·공원·물), `roads.js` 이름 있는 도로,
  `districts.js` 블록 채움 규칙, `places.js` 개별 랜드마크 건물,
  `names.js` 건물 종류 낱말, `interior` 구성은 `world/interior.js`.

## 이름 정책

**지어낸 고유명사를 쓰지 않는다.**

- 실제로 확인한 이름만 데이터에 적는다: 역·학교·행정복지센터·도서관·마트·산업단지·
  아파트 단지·도로·산·수로. 확인한 주소는 해당 항목 주석에 남긴다.
- 이름을 알 수 없는 건물(골목 상가, 단독주택, 공장동, 농막)은 **도로명주소**로 부른다.
  `world/buildings.js` 의 `buildingAddress()` 가 가장 가까운 이름 있는 도로를 찾아
  실제 규칙대로 번호를 매긴다 — 도로 시작점부터 20m마다 1씩, 왼쪽 홀수 오른쪽 짝수.
  그래서 지도에 "김포한강8로 66", "황금로 45 공장" 같은 이름이 붙는다.

## 좌표 정확도

- 뼈대(구래·마산·양촌역, 김포한강로/김포대로/김포한강3·5·7·8·9로, 양촌일반산업단지와
  학운1~7단지, 가현산, 김포대수로, 학교·관공서)는 실제 위치와 주소에 맞췄다.
  산업단지 폴리곤은 김포시 고시 면적(양촌 1,686,493㎡ · 학운2 634,028㎡ ·
  학운3 958,131㎡ · 학운5 893,364㎡ · 학운7 186,749㎡)에 맞춰 크기를 잡았다.
- 아파트 단지 폴리곤은 실제 단지 규모(300×250m 안팎)에 맞췄지만 경계선까지 같지는 않다.
  단지 안 동 배치와 동 번호는 절차적으로 만든 것이다.
- 개별 상가 건물의 위치와 번지수는 실제와 다르다. 도로명과 대략의 번호대만 맞다.

## 더 정확하게 만들려면

`tools/bake_osm.py` 를 망이 열린 개발 머신에서 한 번 돌려 OSM Overpass 결과를
`regions.osm.js` / `roads.osm.js` / `places.osm.js` 로 굽고, `index.js` 의 import 를
그쪽으로 바꾸면 된다. 스키마는 손으로 쓴 파일과 같다.
(이 작업을 한 환경에서는 overpass-api.de 를 포함한 지도 API 가 전부 막혀 있어
검색으로 확인한 실제 이름과 주소를 손으로 넣었다.)
