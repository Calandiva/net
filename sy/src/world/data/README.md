# world/data — 지역 데이터

지형·도로·건물은 **실제 데이터를 구운 것**이고, 사람·사건·아이템은 지어낸 것이다.

## 구운 파일 (손으로 고치지 않는다)

| 파일 | 내용 | 다시 굽는 법 |
|---|---|---|
| `roads.js` | 도로 중심선 3,000여 개 + 실제 도로명 | `python3 tools/bake_overture.py` |
| `footprints.js` | 건물 외곽선 10,000여 채 (중심·크기·각도) + 실제 이름 | 〃 |
| `ground.js` | 토지이용·수계·지형 구역, 행정동 이름표 | 〃 |
| `landmarks.js` | 이름난 시설의 층 구성·안내문 | 〃 (`NOTES` 를 고친다) |

원본은 **Overture Maps** (OpenStreetMap 기여자, ODbL). `tools/overture_fetch.py` 가
공개 S3 버킷에서 우리 지역만 잘라 받아 `tools/overture-cache/` 에 둔다(커밋하지 않는다).
좌표는 **타일 단위**로 구워져 있고, 기준은 `config.js` 의 `GEO` 다 — 베이커의 상수와
반드시 같아야 한다.

## 손으로 쓰는 파일

- `npcs.js`, `npcs_extra.js` 사람들의 역할과 대사
- `events.js`, `events_odd.js` 건물과 길에서 벌어지는 일
- `names.js` 건물 종류 낱말

## 이름 정책

**지어낸 고유명사를 쓰지 않는다.**

- 건물 이름은 데이터에 있는 실제 이름(상호·시설명)만 쓴다.
- 이름을 알 수 없는 건물은 **도로명주소**로 부른다. `world/buildings.js` 의
  `buildingAddress()` 가 가장 가까운 이름 있는 도로를 찾아 실제 규칙대로 번호를 매긴다 —
  도로 시작점부터 20m마다 1씩, 왼쪽 홀수 오른쪽 짝수. 그래서 "김포한강8로 66" 이 붙는다.
- **사람과 사건은 전부 허구다.** 실제 인물·업체·사고와 무관하다. 실제를 반영한 것은
  지리뿐이다.
