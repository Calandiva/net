# 〈구래〉

김포 구래동에서 양촌공단까지 걸어서 출근하는 탑뷰 도트 게임.
브라우저에서 돌아가고, 서버도 설치도 필요 없다. `index.html` 을 열면 그만이다.

> 08:10, 구래역 앞. 첫 출근이다. 양촌공단까지는 걸어서 두 시간쯤 걸리고, 아홉 시까지는 가야 한다.
> 가는 길에 자판기, 비상벨, 소화전, 분전반, 압력 밸브 같은 것들이 있다. 만지지 않아도 된다.

## 실행

- `index.html` 을 더블클릭하거나, 정적 호스팅에 올리면 된다.
- 소스를 고쳤다면 `python3 build.py` 로 `index.html` 을 다시 굽는다.

## 무엇이 들어 있나

- **약 6.5km × 6.1km 의 김포 서북부.** 구래동·마산동·양곡·양촌산업단지·학운산업단지·가현산·
  한강신도시 호수공원. 실제 위경도 위에 얹었고, 세 역(구래·마산·양촌)과 간선도로가 뼈대다.
- **2,700여 채의 건물. 전부 들어갈 수 있다.** 아파트 한 동, 골목 안 분식집, 공장, 학교, 파출소까지.
  실내는 들어가는 순간 만들어지고, 층이 있으면 계단이나 엘리베이터로 오르내린다.
- **그림은 전부 코드가 그린다.** 이미지 파일이 한 장도 없다. 타일도 사람도 건물도
  시드에서 나오므로, 같은 시드면 언제나 같은 동네가 나온다.
- **28가지 결말.** 아무것도 만지지 않고 제시간에 도착하는 것도 결말이고, 마트 분전반을 내리고
  공장 밸브를 돌리는 것도 결말이다. 못 본 결말은 목록에 힌트만 뜬다.

## 만든 방식에 대해

- 지도 데이터는 손으로 넣은 실제 좌표(역·도로·산단·공원·학교·관공서)와, 그 사이를 메우는
  절차적 블록 규칙의 조합이다. 개별 상가나 아파트 동의 위치까지 실제와 같지는 않고,
  상호명은 지어낸 것이다. OpenStreetMap 데이터로 갈아끼우는 스크립트(`tools/bake_osm.py`)를
  같이 넣어 두었다.
- 구조와 규약은 `CLAUDE.md` 에 적어 두었다. 동네를 늘리거나 결말을 추가하려면 그쪽을 보면 된다.
