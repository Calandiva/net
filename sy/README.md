# 〈구래〉

김포 구래동에서 양촌일반산업단지까지 걸어서 출근하는 탑뷰 도트 게임.
브라우저에서 돌아가고, 서버도 설치도 필요 없다. `index.html` 을 열면 그만이다.

> 08:10, 구래역 앞. 첫 출근이다. 양촌일반산업단지까지는 걸어서 한 시간 남짓, 아홉 시까지는 가야 한다.
> 가는 길에 자판기, 비상벨, 소화전, 분전반, 압력 밸브 같은 것들이 있다. 만지지 않아도 된다.
> 사람들은 가끔 뭔가를 하나 쥐여 준다. 손은 하나뿐이라 하나만 들 수 있다.
> 그리고 아침 여덟 시의 구래동에는, 생각보다 여러 가지가 일어난다.

## 실행

- `index.html` 을 더블클릭하거나, 정적 호스팅에 올리면 된다.
- 소스를 고쳤다면 `python3 build.py` 로 `index.html` 을 다시 굽는다.

**모바일**은 왼쪽 화면을 끌어 걷고(끝까지 밀면 달린다), 오른쪽 아래 버튼으로
만지기 · 달리기 · 지도 · 쓰기를 한다. 오른쪽 위 미니맵을 누르면 전체지도가 열리고,
지도에서 갈 곳을 누르면 그쪽으로 알아서 걸어간다.

## 무엇이 들어 있나

- **약 5.6km × 6.7km 의 김포 서북부 — 실제 지도 그대로.** 구래동·마산동·장기동·양촌읍·
  양곡·학운 산업단지·가현산. 도로 3,000여 개와 건물 10,000여 채가 실제 위치·모양·이름 그대로
  들어 있다 (OpenStreetMap 기여자 · Overture Maps, ODbL).
- **이름은 실제 이름이다.** 구래역·마산역·양촌역, 이마트 김포한강점, 두원타워, 메가박스,
  김포한가람초등학교, 양곡도서관, 구래동 행정복지센터, 그리고 골목의 실제 가게들까지.
  이름을 알 수 없는 건물은 지어내지 않고 도로명주소로 부른다 — "김포한강8로 66" 처럼.
- **10,000여 채의 건물. 전부 들어갈 수 있다.** 아파트 한 동, 골목 안 상가, 공장, 학교까지.
  실내는 들어가는 순간 만들어지고, 층이 있으면 계단이나 엘리베이터로 오르내린다.
  (실내 구조는 절차 생성이라 실제 내부와는 무관하다.)
- **그림은 전부 코드가 그린다.** 이미지 파일이 한 장도 없다. 색은 항공사진 톤을 따라가서,
  아파트 옥상은 녹회색 방수, 공장 지붕은 파란 샌드위치 패널, 도로 중앙선은 노란색이다.
- **아이템 38가지.** 소화기, 꽃 한 다발, 장난감 레이저총, 확성기, 부적, 도토리 한 줌…
  전부 사람에게서 받는다. 바닥에 떨어져 있는 것은 없고, 한 번에 하나만 들 수 있다.
- **사건 22가지.** 아침부터 문을 연 술집, 멈춘 엘리베이터, 상가 3층의 연기, 가현산의 의식,
  논 한가운데 내려앉은 것, 갯벌에서 올라온 것, 도면에 없는 지하 문…
  **무엇을 들고 마주쳤느냐로 결과가 갈린다.** 외계인에게 꽃을 주는 것과 레이저총을 쏘는 것,
  소화기를 뿌리는 것은 각각 다른 하루다.
- **165가지 결말.** 아무것도 만지지 않고 제시간에 도착하는 것도 결말이고, 차에 치여
  두원타워 3층 병원에서 하루를 접는 것도, 지하에서 뭔가를 잘못 건드리는 것도 결말이다.
  결말은 게임의 끝이 아니라 그날 하루가 그렇게 끝났다는 뜻이다. 못 본 결말에는
  어디서 무엇을 써야 하는지가 힌트로 뜬다.

## 만든 방식에 대해

- 지형·도로·건물은 Overture Maps 공개 데이터(OpenStreetMap 기여자, ODbL)를 받아
  게임 좌표로 구운 것이다. `tools/overture_fetch.py` 로 받고 `tools/bake_overture.py` 로 굽는다.
  건물 모양은 회전 사각형으로 줄인 근사치이고, 실내와 사람·사건은 전부 지어낸 것이다.
- 지도 데이터 출처: **© OpenStreetMap 기여자 · Overture Maps Foundation (ODbL)**.
- 구조와 규약은 `CLAUDE.md` 에 적어 두었다. 동네를 늘리거나 결말을 추가하려면 그쪽을 보면 된다.
