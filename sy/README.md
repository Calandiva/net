# 〈구래〉

김포 구래동에서 양촌일반산업단지까지 걸어서 출근하는 탑뷰 도트 게임.
브라우저에서 돌아가고, 서버도 설치도 필요 없다. `index.html` 을 열면 그만이다.

> 08:10, 구래역 앞. 첫 출근이다. 양촌일반산업단지까지는 걸어서 한 시간 남짓, 아홉 시까지는 가야 한다.
> 가는 길에 자판기, 비상벨, 소화전, 분전반, 압력 밸브 같은 것들이 있다. 만지지 않아도 된다.

## 실행

- `index.html` 을 더블클릭하거나, 정적 호스팅에 올리면 된다.
- 소스를 고쳤다면 `python3 build.py` 로 `index.html` 을 다시 굽는다.

## 무엇이 들어 있나

- **약 6.5km × 6.0km 의 김포 서북부.** 구래동·마산동·유현리·양곡·양촌일반산업단지·
  학운1~7일반산업단지·가현산. 실제 위경도 위에 얹었고, 세 역(구래·마산·양촌)과
  김포한강3·5·7·8·9로, 김포대로, 황금로가 뼈대다.
- **이름은 실제 이름이다.** 이마트 김포한강점, 두원타워(8층 메가박스), 한가람마을 우미린,
  김포한강예미지, 한강신도시 3차 푸르지오, 김포구래초등학교, 김포시 마산도서관,
  양촌일반산업단지… 이름을 알 수 없는 건물은 지어내지 않고 도로명주소로 부른다.
  골목을 걷다 보면 "김포한강8로 66" 같은 이름표가 뜬다.
- **2,300여 채의 건물. 전부 들어갈 수 있다.** 아파트 한 동, 골목 안 상가, 공장, 학교,
  물류창고까지. 실내는 들어가는 순간 만들어지고, 층이 있으면 계단이나 엘리베이터로 오르내린다.
- **그림은 전부 코드가 그린다.** 이미지 파일이 한 장도 없다. 색은 항공사진 톤을 따라가서,
  아파트 옥상은 녹회색 방수, 공장 지붕은 파란 샌드위치 패널, 도로 중앙선은 노란색이다.
- **28가지 결말.** 아무것도 만지지 않고 제시간에 도착하는 것도 결말이고, 이마트 분전반을
  내리고 학운2단지 폐수처리장 밸브를 돌리는 것도 결말이다. 못 본 결말은 목록에 힌트만 뜬다.

## 만든 방식에 대해

- 지도 데이터는 확인한 실제 좌표·주소·고시 면적(역·도로·산업단지·학교·관공서·아파트 단지)과,
  그 사이를 메우는 절차적 블록 규칙의 조합이다. 단지 안 동 배치나 개별 상가의 번지수까지
  실제와 같지는 않다. OpenStreetMap 데이터로 갈아끼우는 스크립트(`tools/bake_osm.py`)를
  같이 넣어 두었다.
- 구조와 규약은 `CLAUDE.md` 에 적어 두었다. 동네를 늘리거나 결말을 추가하려면 그쪽을 보면 된다.
