# sy — 〈구래〉

김포 구래동에서 양촌공단까지를 배경으로 한, 웹에서 돌아가는 탑뷰 도트 그래픽 도보 어드벤처 게임.

**구래동에서 출발해 양촌일반산업단지에 닿으면 끝난다.** 가는 길에 무엇을 건드렸고,
무엇을 들고 무엇을 마주쳤느냐로 하루가 갈린다. 결말은 165가지.
〈Please, Don't Touch Anything〉처럼, 설명해 주지 않는 물건들을 만져 보다가 발견하는 쪽이다.
결말은 게임의 끝이 아니라 "그날 하루가 이렇게 끝났다" 는 뜻이다 (`R` 로 다시 시작한다).

## 실행

```
python3 build.py          # src/*.js → index.html (의존성 없음, 수 초)
open index.html           # 파일 더블클릭으로 실행. 서버 불필요
node tools/check_path.mjs # 출발점에서 목적지까지 걸어갈 수 있는지 점검
```

## 실행 환경 제약

- **서버 없음.** `index.html` 을 파일로 열거나 정적 호스팅만으로 완전히 동작한다. 백엔드 없음.
- **빌드 단계가 하나 있다.** 원래 계획은 빌드 없이 ES 모듈을 직접 부르는 것이었지만,
  브라우저는 `file://` 에서 모듈 로딩을 CORS 로 막는다. 소스는 진짜 ES 모듈로 두고,
  `build.py` 가 그것들을 IIFE 로 감싸 `index.html` 한 파일에 넣는다.
  번들러도 의존성도 없다(파이썬 표준 라이브러리만). 결과물은 여전히 서버 없이 돈다.
- 세이브는 발견한 결말 목록뿐이고 `localStorage` 를 쓴다. 막혀 있어도 게임은 그대로 돌아간다.

## 에셋 방침

**외부 이미지 생성 API를 쓰지 않는다.** 스프라이트, 타일, 건물 외관은 전부 코드가 만든다.

- 절차적 생성(노이즈, 시드 기반 팔레트 변주, 규칙 기반 도트 패턴)으로 런타임에 캔버스로 그려낸다.
- 생성 로직은 `src/render/sprites.js` 하나에 격리한다. 나중에 실제 이미지 에셋으로 갈아끼우더라도
  이 파일만 교체하면 되도록.
- 모든 생성은 시드 기반으로 재현 가능하다. 시드는 `src/config.js` 의 `SEED`.
- 웹에서 가져온 이미지는 저작권 문제로 쓰지 않는다.

## 코딩 규약

유지보수 편의가 최우선 요구사항이다.

- 매직 넘버 금지. 조정 가능한 값은 전부 `config.js` 로.
- 지역 데이터와 렌더링을 섞지 않는다. 건물이나 층을 추가할 때 `world/data/` 만 건드리면 된다.
- 파일 하나가 커지면 쪼갠다. 위 구조에 없는 관심사가 생기면 새 파일을 만들고 이 문서를 갱신한다.
- 주석은 한국어로.
- **번들러가 단순하게 유지되도록 지키는 것들** (`build.py` 가 강제한다):
  - `import { a, b } from './x.js';` 형태만 쓴다. default·별칭·네임스페이스 import 금지.
  - `export const/let/var/function/class 이름` 형태만 쓴다. `export {}` 와 `export default` 금지.
  - 새 파일을 만들면 `build.py` 의 `MODULES` 목록에 의존성 순서로 추가한다.
  - 모듈 사이에 같은 이름을 export 하지 않는다 (빌드가 이름 충돌을 잡아 준다).

## 맵 데이터 — 실제 지형

**지형·도로·건물은 실제 데이터다.** Overture Maps 공개 데이터(OpenStreetMap 기여자, ODbL)를
받아 게임 좌표로 구웠다.

```
python3 tools/overture_fetch.py   # 망이 열린 곳에서 한 번 (S3 공개 버킷, 수십 MB)
python3 tools/bake_overture.py    # src/world/data/*.js 를 다시 굽는다
python3 build.py
```

구운 결과 (손으로 고치지 않는다)

| 파일 | 내용 |
|---|---|
| `world/data/roads.js` | 도로 중심선 3,000여 개 + 실제 도로명 (김포한강8로, 황금로 …) |
| `world/data/footprints.js` | 건물 외곽선 10,000여 채 (회전 사각형) + 실제 이름 750여 개 |
| `world/data/ground.js` | 토지이용·수계·지형 구역 1,000여 개 + 행정동 이름표 |
| `world/data/landmarks.js` | 이름난 시설의 층 구성 (`tools/bake_overture.py` 의 `NOTES`) |

- **좌표계**: `config.js` 의 `GEO` 와 `tools/bake_overture.py` 의 상수는 같은 값이어야 한다.
  구운 좌표가 그 기준으로 만들어져 있다.
- **건물은 기울어 있다.** 실제 건물은 길을 따라 앉아 있으므로 회전 최소 사각형
  (`중심 · 가로 · 세로 · 각도`)으로 담고, 칸 판정은 `rectContains()` 가, 그리기는
  `scene.drawBuilding()` 의 회전 변환이 맡는다. 높은 건물은 조금 기운 정도면 반듯하게 세운다.
- **이름**: POI(상호·시설명)를 건물 외곽선에 얹어 실제 이름을 붙인다. 이름을 알 수 없는
  건물은 지어내지 않고 도로명주소로 부른다 — `buildingAddress()` 가 실제 규칙
  (도로 시작점부터 20m 마다 1씩, 왼쪽 홀수·오른쪽 짝수)대로 "김포한강8로 66" 을 만든다.
- **출처 표기 의무**: ODbL 데이터라 도움말 화면과 README 에 출처를 밝힌다. 지우지 말 것.

정확하지 않은 것
- 건물 모양은 회전 사각형으로 줄인 근사치다 (ㄱ자·ㄷ자 건물도 사각형 하나로 담긴다).
- 층수는 데이터에 있으면 그걸 쓰고, 없으면 종류로 짐작한다.
- 실내는 전부 절차 생성이다. 실제 내부 구조와는 무관하다.

## 축척과 색

- 타일 하나 = 2.5m (`GEO.metersPerTile`). 지도 전체는 약 6.5km × 6.0km.
- 도로 폭은 차선 수 기준이다. 자동차전용 25m, 6~8차선 20m + 보도, 4차선 15m, 이면도로 10m.
- **차도는 타일이 아니라 선으로 그린다.** 타일로 칠하면 비스듬한 길이 계단처럼 각지고
  중앙선이 끊긴다. 지면 래스터는 도로 안쪽만 칠하고(가장자리 한 겹은 비운다),
  `render/scene.js` 의 `strokeRoads()` 가 아스팔트 패턴으로 선을 그은 뒤 노란 중앙선과
  흰 차선을 얹는다. 상가 블록의 포장 마당은 차도와 헷갈리지 않게 `GROUND.ASPHALT` 로 따로 둔다.
- 색은 항공사진 톤을 따라간다. 논은 여름 녹색, 아스팔트는 진회색에 **노란 중앙선**,
  아파트는 베이지 벽에 녹회색 옥상 방수, **공장 지붕은 파란 샌드위치 패널**,
  상가 간판은 건물마다 다른 색, 비닐하우스는 흰 비닐. 값은 전부 `render/palette.js` 에 있다.

## 게임 규칙

- 08:10 에 구래역 앞에서 출발. 09:00 까지 양촌일반산업단지(`GAME.goalRegions`)에 닿는 것이
  기본 목표. 학운 단지들은 가는 길에 있으므로 목적지가 아니다 — 그래야 산업단지 안의
  물건(출입증·밸브·지게차)을 도착 전에 만질 수 있다.
  게임 시계는 실제 시간의 6배로 흐른다 (`GAME.timeScale`).
- 목적지에 닿는 순간 `game/endings.js` 를 위에서부터 검사해 처음 맞는 결말이 그 판의 결말이 된다.
- 일부 결말(`when: 'any'`)은 도착 전에 즉시 끝난다. 폭발이나 자수, 사건의 결과 같은 것들.
- 발견한 결말은 `localStorage` 에 남고 `L` 키 목록에서 볼 수 있다. 못 본 결말에는
  어디서 무엇을 써야 하는지가 힌트로 뜬다. 목록은 쪽으로 넘긴다 (← →).
- **차도에 뛰어들면 차에 치인다.** 하루가 끝나지는 않고 걸음이 반으로 준다.
  그 상태로 두원타워 3층 병원에 올라가면 오늘은 거기서 끝난다.

### 아이템

- 아이템은 **사람에게서만** 얻는다. 바닥에 떨어져 있지 않다. 말을 걸다 보면
  줄 것을 가진 사람이 나온다 (`LIFE.giftChance`). 어떤 아이템을 가진 사람이
  어디에 있는지는 `game/data/items.js` 의 `give` 가 정한다 (건물 종류 · 지역 성격).
- **한 번에 하나만 든다.** 이미 들고 있으면 "놓고 받을지" 를 대화창에서 고른다.
- `Q`(모바일은 쓰기 버튼)로 쓴다. 사건 앞에서 쓰면 그 사건의 결과가 갈리고,
  아무 데서나 쓰면 물건마다 정해진 한 줄이 나온다. `투척` 인 물건은 쓰면 없어진다.

### 사건

- 사건은 지도 위(또는 건물 안)의 정해진 자리에 있다. `game/data/encounters_*.js`.
- 사건 하나에는 결과가 여럿이고, **무엇을 들고 있느냐로 결과가 갈린다.**
  결과 하나가 그대로 엔딩 하나다 (`encounterEndings()` 가 모아 `ENDINGS` 앞에 붙인다).
- 예: 외계인에게 꽃을 주면 환심을 사고, 레이저총을 쏘면 쓰러뜨리고, 소화기를 뿌리면
  실망시키고, 라디오를 켜면 교신한다. 각각 다른 엔딩이다.
- 가까이 가면 "저쪽에 뭔가 있다" 고 한 번 귀띔한다 (`GAME.noticeEncounter`).

### 실내

- 건물 종류마다 바닥·벽 색이 다르다 (`INTERIOR_THEMES` → `THEME_COLOR`).
  집은 장판, 사무실은 타일 카펫, 학교는 리놀륨, 공장과 지하주차장은 콘크리트.
- 방 이름에 따라 가구가 달라진다. 교실에는 칠판과 줄 맞춘 책상, 급식실에는 배식대,
  병실에는 침대 줄, 민원실에는 창구와 긴 의자, 옷가게에는 행거가 놓인다.
- **사람과 물건은 걸어 닿는 자리에만 놓는다** (`interior.canReach`). 승강장 선로 건너편처럼
  못 가는 자리에 두면 지하철을 못 타는 일이 생긴다.
- **방은 문을 열어야 보인다.** 복도에서 보이는 것은 벽과 문뿐이고, 문을 열거나 들어가면
  그 방이 밝아진다 (`interior.visibleAt()` · `reveal()`). 마트 매장이나 주차장처럼
  문이 없는 통짜 공간은 처음부터 보인다.
- 실내는 외관보다 넉넉하다 (`INTERIOR.scale` 2.4, 최대 68×48 타일). 단독주택과 농막만 작다.
- 건물 종류와 층에 따라 실내 형태가 달라진다 (`world/interior.js` 의 `layoutOf`).
  마트 매장, 지하주차장, 메가박스 상영관, 지하철 승강장, 아파트 세대 복도, 공장 라인.
- 층별 용도는 `world/data/places.js` 의 `floorNames` 에 적는다. 엘리베이터 대화창에
  "8층 메가박스", "지하 2층 주차장" 처럼 뜬다. 적지 않으면 종류로 짐작한다.
- 계단은 모든 건물에 있고, 층수가 많거나 사람이 몰리는 곳(`ELEVATOR_KINDS`)에는
  엘리베이터가 더 있다. 엘리베이터를 누르면 층 선택 대화창이 뜬다.

### 아파트 단지

- 단지마다 `units`(동 수)와 `households`(세대수)를 데이터에 적는다. 동은 자리를 잡은
  순서대로 101동, 102동 … 번호가 붙고 units 를 넘지 않는다.
- 단지에는 관리사무소·경비실·어린이집·단지내상가가 함께 생기고, 마당에는 놀이터와
  주차 한 줄이 들어간다.

### 사람과 사건

- **사람**: `world/data/npcs.js` 에 건물 종류별 역할과 대사를 적는다. 실내 인물은
  `world/indoor.js` 가 층마다 시드로 세우고, 길 위 사람은 `world/actors.js` 가 그 동네
  성격(city·industrial·field·forest)에 맞춰 세운다. 말을 걸면 `ui/dialogue.js` 가 뜬다.
- **사건**: `world/data/events.js` 에 적는다. 건물 한 층마다 시드로 하나 정해지고
  (`LIFE.eventChance`), 눈에 보이는 흔적(연기·상자·물웅덩이·안전콘)과 사람들의 말로
  드러난다. 길 위 사건은 청크마다 정해져 소품과 목격자가 함께 생긴다.
- 실제 지리만 사실이고 사람과 사건은 전부 지어낸 것이다. 실제 인물·업체·사고와 무관하다.
- 사건을 여섯 가지 넘게 보거나 여덟 명 넘게 말을 걸면 그 자체로 결말이 갈린다 (E29 · E30).
- 좀처럼 없는 일은 `world/data/events_odd.js` 에 따로 모았다. 그 자리에 어울리는 일과
  전혀 어울리지 않는 일(실내에 낀 안개, 복도의 소, 팔월의 눈, 길 한가운데 피아노)이 반씩이다.

## 갇히지 않게 하는 것들

플레이어가 어딘가에 끼어 아무 데도 못 가는 것이 제일 나쁜 버그다. 세 겹으로 막는다.

1. **문 앞 두 칸을 비운다** (`BUILDING.doorApron`). 청크를 만들 때 문 앞의 나무·화단을
   지운다. 물이면 보도로 바꾼다.
2. **막힌 문은 옮긴다** (`fixBlockedDoors`). 나중에 놓인 건물이 문을 막으면
   남쪽 벽의 다른 자리 → 동 → 서 → 북 순으로 문을 다시 낸다.
3. **제자리걸음이 이어지면 확인하고 빼 준다** (`checkTrapped` → `map.openSpot`).
   벽을 향해 걷고 있을 뿐이면 그냥 두고, 정말로 갇혔을 때만(`PLAYER.safeArea` 칸도
   못 돌아다닐 때) 가까운 넓은 자리로 옮긴다.

출발 지점도 같은 기준으로 잡는다 (`map.openSpot`). 건물에서 나올 때와 지하철로 이동할 때도
같은 함수를 지난다.

## 성능에서 조심할 것

- **화면 밖 것에는 지도를 묻지 말 것.** 차 천 대가 매 프레임 `map.isSolid()` 를 부르면
  온 지도의 청크를 새로 만들다가 5fps 까지 떨어진다. `traffic.update()` 는 화면 범위를
  받아 그 안의 차만 검사하고, 검사도 이미 만들어 둔 청크에서만 한다 (`map.hasChunk()`).
- 청크는 캔버스에 한 번 굽고 LRU 로 40개만 들고 있는다. 지면이 바뀌면 `scene.invalidate()`.
