# NetForge 망구성도

전산망 구성도를 그리고, **실제 장비의 동작 방식대로 통신이 되는지 검증**하는 브라우저 시뮬레이터.
구성 전체(장비·IP·VLAN·보안존·방화벽 정책·이중화·플로우·화면 상태)가 **URL 해시 한 줄**에 들어갑니다.
서버도, 계정도, 빌드 도구도 필요 없습니다.

---

## 100단계 학습 과정

상단 **학습** 버튼. 장비 한 대 놓기에서 시작해 10개 장, 100개 과제로 난이도가 올라갑니다.

| 장 | 주제 | 배우는 것 |
|---|---|---|
| 1 | 기초 | 배치 · 연결 · IP · 포트 · 끊긴 원인 읽기 |
| 2 | 주소와 구간 | 서브넷 · VLAN · 존 · 사설/공인 · 주소 계획 |
| 3 | 라우팅 | 정적 · 기본 경로 · SVI · 넥스트홉 · 루프 · 동적 라우팅 |
| 4 | 방화벽 | 존 · implicit deny · first-match · 포트 제한 · 다단 |
| 5 | NAT 와 경계망 | SNAT · DNAT · 포트 변환 · 프록시 · DNS · 서비스 공개 |
| 6 | 부하분산 | VIP · 풀 · 헬스체크 · 알고리즘 · 지속성 · 비대칭 경로 |
| 7 | 이중화 | VRRP · A/S · 이중 결선 · 하트비트 · SPOF 제거 |
| 8 | 데이터 계층 | 복제 방식별 RPO/RTO · SCAN VIP · MPIO · 캐시 · 백업 |
| 9 | 보안 심화 | IPS · fail-open · WAF · DMZ · 관리망 · 배스천 · 망분리 |
| 10 | 종합 설계 | 3-Tier · 무결점 · 고장 수리 · 대규모 · 무중단 · 졸업 과제 |

- 빈 화면부터 만드는 과제와, 일부러 **고장난 구성을 넘겨받아 고치는** 과제가 섞여 있습니다.
- 조건은 만드는 동안 **실시간으로 체크**됩니다. ○ 가 ✓ 로 바뀌는 걸 보며 진행하면 됩니다.
- 채점: 필수 조건을 모두 채우면 통과(70점), 추가 조건까지 채우면 100점. 등급 S/A/B/C/D.
- 진행 상황은 브라우저에 저장되지만, 없어도 아무 과제나 바로 시작할 수 있습니다.

## 조작법 (Max/MSP 방식)

| 하고 싶은 것 | 조작 |
|---|---|
| 장비 배치 | 팔레트에서 끌어놓기 · 클릭 · **캔버스 더블클릭**(이름 입력해 바로 추가) |
| 연결 | 노드 가장자리 **포트에서 끌어** 대상 장비에 놓기 (붙을 포트가 미리 표시됨) |
| 이동 | 드래그. 다른 장비와 줄이 맞으면 자동 스냅 + 안내선, `Alt` 로 해제 |
| 여러 개 선택 | 빈 곳 드래그로 범위 선택 · `Shift`+클릭 추가 · `Ctrl+A` 전체 |
| 화면 이동 | `Space`+드래그 · 가운데 버튼 드래그 · `Shift`+휠(좌우) |
| 메뉴 | **우클릭** — 장비 / 링크 / 빈 곳 / 다중선택마다 다른 메뉴 |
| 설명 보기 | 장비·포트·링크에 **마우스 올리기** (어시스트 말풍선) |
| 정렬 | 여러 개 선택 → 우클릭 → 정렬 / 간격 균등 |
| 기타 | `방향키` 이동 · `Ctrl+C/V/D` 복사·붙여넣기·복제 · `F2` 이름변경 · `Del` 삭제 |

### 노드 상하좌우 포트의 의미

| 위치 | 역할 | 쓰임새 |
|---|---|---|
| **▲ 위** | 업링크 | 상위망 방향 — 인터넷·코어·상단 스위치로 올라가는 회선 |
| **▼ 아래** | 다운링크 | 하위망 방향 — 서버·단말·하단 스위치로 내려가는 회선 |
| **◆ 좌·우** | 피어 | 같은 계층끼리 — 이중화 하트비트, 스위치 스택/MLAG, DB 복제 |

포트는 **네트워크 계층 깊이**(인터넷에서 몇 홉 떨어져 있는가)로 자동 결정됩니다.
장비를 화면 어디로 옮겨도 위는 언제나 업링크입니다. 우클릭 메뉴에서 특정 포트로 고정하거나
“포트 자동 배치로 되돌리기”로 해제할 수 있습니다. 한 면에 여러 회선이 붙으면 패치 패널처럼
자리를 나눠 겹치지 않게 그립니다.

## 실행 방법

### 1. 로컬 파일로 바로 실행
`index.html` 을 더블클릭하면 됩니다 (`file://`). 모든 기능이 동작하며,
인터넷이 없으면 웹폰트만 시스템 글꼴로 대체됩니다.

### 2. GitHub Pages
이 저장소는 이미 `main` 에 올라가 있습니다. 남은 건 Pages 켜기 한 번뿐입니다.

**Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save**

1~2분 뒤 **https://calandiva.github.io/net/** 에서 열립니다.

이후 수정할 때는:
```bash
python build.py
git add -A && git commit -m "메시지" && git push
```
(`.nojekyll` 이 있어 Jekyll 전처리를 건너뜁니다. 빌드 액션은 필요 없습니다.)

### 3. Vercel
```bash
npx vercel deploy --prod
```
빌드 명령 없음 / 출력 디렉터리 = 프로젝트 루트. `vercel.json` 이 이미 들어 있습니다.
Vercel 대시보드에서 폴더를 드래그해 올려도 됩니다.

### 4. 그 밖의 정적 호스팅
Netlify, S3+CloudFront, Nginx, 사내 웹서버 — `index.html` 하나만 올리면 끝입니다.

## 저장 · 불러오기 · 공유

| 방법 | 형식 | 쓰임새 |
|---|---|---|
| **URL 복사** | `…/index.html#N1.eJyt…` | 링크만 보내면 상대방 화면에 그대로 재현 |
| **저장 → 압축 텍스트** | `N1.eJyt…` 한 줄 | 메신저·이슈·위키에 붙여넣기 |
| **저장 → JSON** | 사람이 읽고 편집 가능 | 형상관리(Git) 에 커밋, 리뷰 |
| **저장 → .txt 파일** | 압축 텍스트 한 줄 | 오프라인 보관 |
| **불러오기** | 위 넷 중 무엇이든 | 형식 자동 판별 |

### URL 인코딩 규칙
1. 문서를 배열 표현으로 정규화 — 노드 `[타입번호, x, y, 속성]`, 링크 `[a인덱스, b인덱스, 매체]`,
   노드 참조는 배열 인덱스로 치환
2. 타입 기본값과 같은 속성은 생략
3. `JSON → UTF-8 → DEFLATE(raw) → base64url`
4. `location.hash = "N1." + payload` (`N1`=압축, `N0`=평문 폴백)

해시(`#`)는 서버로 전송되지 않으므로 구성 정보가 외부로 나가지 않습니다.
29개 장비 / 60개 링크 규모가 약 2.9 KB 입니다.

## 무엇을 시뮬레이션하는가

| 영역 | 구현한 동작 | 근거 |
|---|---|---|
| 방화벽 정책 | 위→아래 first-match, 미매칭 시 동일 존 허용 / 다른 존 차단 | Palo Alto PAN-OS |
| NAT | DNAT 는 라우팅 전 목적지 변환, SNAT 는 송신 인터페이스에서 출발지 변환 | PAN-OS NAT 정책 |
| 로드밸런싱 | RR / Ratio / Least Conn / WLC / Fastest / Observed / Predictive / Source·URI Hash | F5 BIG-IP LTM |
| 세션 지속성 | Source Address, Cookie Insert(L7 전용), SSL Session ID, Destination | F5 LTM Persistence |
| 게이트웨이 이중화 | 가상 IP + 우선순위 + Preempt | VRRP(RFC 5798) / HSRP / GLBP |
| 방화벽 이중화 | A/S 쌍이 동일 인터페이스 IP 를 공유, 장애·링크다운 시 인수 | PAN-OS / FortiGate A-P HA |
| DB 이중화 | RAC / Data Guard / Always On / FCI / 반동기 / Group Replication / 스트리밍 / Patroni 별 RPO·RTO | Oracle MAA, MySQL, PostgreSQL |
| 인라인 보안장비 | 다운 시 fail-open 바이패스면 회선 유지, 아니면 단절 | IPS·DDoS·WAF 바이패스 모듈 |
| 라우팅 | 연결·정적·기본경로 최장 프리픽스 매칭, OSPF/BGP/EIGRP/IS-IS 최단경로 학습 | 일반 라우팅 원리 |

단방향 포워딩만 계산하며, 상태 기반 방화벽의 리턴 트래픽은 허용된 것으로 봅니다.

## 검증 항목

- **연결성** — 미연결 노드, 링크 단절, 투과 장비 다운, L2 경로 부재
- **주소** — IP 미설정·충돌, 구간 서브넷 불일치, 게이트웨이 대역 오류·응답 없음
- **라우팅** — 경로 없음, 넥스트홉 불일치, 루프
- **보안** — implicit deny 차단, any-any 허용, 존 미지정, 인터넷 직결, 아웃바운드 NAT 누락
- **부하분산** — VIP·풀 미설정, 멤버 포트 불일치, SNAT 없는 비대칭 경로, L4 에 Cookie 지속성
- **가용성** — 이중화 짝/VIP 누락, 하트비트 없음, 단일 상단 스위치, DB 단일 인스턴스, 스토리지 단일 경로
- **SPOF 분석** — 모든 장비·링크를 하나씩 다운시켜 어떤 플로우가 끊기는지 전수 계산

## 랜덤 구성도

생성기는 **스펙 굴리기 → 조립 → 검증 → 실패 시 재시도** 구조입니다. 누를 때마다 규모 · 장비 조합 ·
연결 방식 · 주소 체계가 새로 정해지지만, 검증을 통과할 때까지 다시 굴리므로 통신은 항상 성립합니다.
IP · VLAN · 보안존 · 방화벽 정책 · 이중화 · LB 풀 · 검증 플로우가 모두 채워진 채로 나옵니다.

- 표준 3-Tier DMZ
- 금융 / 공공형 다계층 보안망
- 중소규모 통합망
- 컨테이너 플랫폼 (K8s + Patroni + Redis)
- 본사 ─ 지사 WAN
- 무작위 (극단 포함) — 방화벽 10단에 서버 1대 같은 형태도 낮은 확률로 나옵니다

측정 결과: 일반 40회 40/40 통과(서로 다른 구성 40종), 극단 모드 40회 40/40 통과, 장비 8~40대.

## 이 레포의 다른 것 — `sy/` 와 `ggyemssbbyokk/`

`sy/` 에는 별개 프로젝트인 **〈구래〉** 가 들어 있습니다. 김포 구래동에서 양촌공단까지
걸어서 출근하는 탑뷰 도트 어드벤처로, 역시 서버 없이 `sy/index.html` 하나로 돌아갑니다.
자세한 것은 `sy/README.md` 를 보세요.

`ggyemssbbyokk/` 에는 **GGYEMSSBBYOKK** 이 들어 있습니다. 기타·베이스·건반·우쿨렐레
코드 사전과 크로매틱 튜너, 메트로놈입니다. 코드 이름을 치면 악기마다 운지를 여러 벌 찾아 주고,
몇 개만 잡을 때 무엇을 남기고 무엇을 빼는지까지 보여 줍니다. 튜너는 음정 찾는 알고리즘을
여섯 가지 중에서 골라 쓸 수 있습니다. 역시 `ggyemssbbyokk/index.html` 하나로 돌아갑니다.
자세한 것은 `ggyemssbbyokk/README.md` 를 보세요.
